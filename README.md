# Riftbound Live Coach (beta)

A free, read-only overlay for [play.riftatlas.com](https://play.riftatlas.com). It reads the board and tells you what matters right now. It never clicks or changes the game.

- **Glance**: the 3–4 things that matter this turn: what to play, where to move, who wins each fight, triggers you might miss
- **Board**: every card in play with its text and its real Might (Shield, gear, battlefield and legend bonuses included)
- **Judge**: ask a rules question about the current board; answers cite the Core Rules
- **Sideboard**: swaps based on the cards your opponent has shown
- **Stats / Tests**: your results by deck, deck version and opponent, recorded automatically

Works with any legend and any deck. It reads your list from the RiftAtlas lobby. No account and no AI key are needed: the AI button is optional and off by default.

## Install (about 2 minutes)
1. Install **Tampermonkey** for your browser (Chrome, Edge, Firefox or Brave).
2. **Chrome / Edge / Brave only:** open the extensions page (`chrome://extensions`), click **Details** on Tampermonkey and turn on **Allow User Scripts**. Without this, Chrome won't run the script.
3. Open this link and click **Install**:
   https://raw.githubusercontent.com/ins0dus/riftbound-coach/main/rb-coach.user.js
4. Go to play.riftatlas.com and open your deck in the lobby once so the coach can read it. Then start a game. The coach panel appears on the right side.

Updates install automatically. To get one right away, use Tampermonkey → **Check for userscript updates**.

## Beta testers: how to help
- See a wrong or confusing line? Tap **👎** next to it, pick a reason and add a note. It's sent to us automatically, with no account needed.
- Tell us what deck you're on and anything the coach missed.
