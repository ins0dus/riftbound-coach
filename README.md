# Riftbound Live Coach

A read-only Tampermonkey overlay for [play.riftatlas.com](https://play.riftatlas.com). It reads the board and suggests plays. It never clicks or changes the game.

- **Now**: trigger/ability reminders ("Don't miss") and step-by-step suggestions
- **Board**: every card in play with its text
- **Sideboard**: swap suggestions from the opponent's cards seen this match
- **Ask**: card/keyword lookups offline; full answers with your own Claude API key (⚙)

## Install
1. Install the Tampermonkey extension.
2. Open https://raw.githubusercontent.com/ins0dus/riftbound-coach/main/rb-coach.user.js and click **Install**.

Updates install automatically (Tampermonkey → "Check for userscript updates" to get one right away).
